## How this was generated

```bash
make mutate    # full-module mutation testing (~24 min)
# or, for a single file (incremental PR gating):
make mutate-pkg PKG=serve.go
```

Reports land in [`runs/`](runs/) as JSON. CI runs the full module
weekly on the schedule defined in
[`.github/workflows/mutation.yml`](../../.github/workflows/mutation.yml)
and fails a run on a regression of more than 2pp.
