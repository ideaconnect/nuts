## Not covered, checked by hand

Go's coverage profile marks neither constant declarations nor the `case`
expressions of tagless `switch` statements, so gremlins cannot see a test run
them and does not execute their mutants ([scope.md](scope.md)). Every one of
the 40 was applied by hand with
[`scripts/mutate-by-hand.py`](../../scripts/mutate-by-hand.py) and the whole
package run against it:

| Lines | What | Result |
| --- | --- | --- |
| `provision.go` 38, 53, 62, 80, 84, 113, 289; `serve.go` 394; `shared.go` 40 | Constants: the `-1` sentinels and the timeouts, backoffs and retry base | All killed; the metadata-read and consumer-create timeouts by the suite's deadline, since a zero timeout hangs every request. `sharedJoinBackoff` lived until `TestShared_SlowClientFallsBackWithoutLoss` checked that a connection that caught up waits before rejoining. |
| `helpers.go` 169–179 | The formatter's escaping cases | 10 killed. Turning `\|\|` into `&&` on line 173 (`c == '<' && c == '>'`) is rejected by `go vet` before any test runs. |
| `provision.go` 776, 779 | `nats_idle_heartbeat` validation | 8 killed. `> 0` → `>= 0` was equivalent, because the case also required `>= 15`; the redundant `> 0` is gone, and both mutants of what is left are killed. |
| `serve.go` 803, 808 | Cursor ahead of the stream, cursor below retention | 5 killed. |
| `provision.go` 490, 500 | The NATS async error handler's `err == nil` and `sub != nil` guards | No test raised an asynchronous error. `TestHandler_connectNATS_AsyncErrorsAreCountedAndLogged` now pushes a subscription past its pending limit; both killed. |

## Beyond operators

gremlins only changes operators. Each change on the branch was also checked
with statement-level mutants written by hand (a deleted call, a reverted fix,
a `select` case that can never fire, a changed constant). The ones that
survived at first each led to a test:

| Area | Hand mutants | What survived at first |
| --- | --- | --- |
| Each phase of the plan (`gremlins --diff` per change) | Reverse mutants that undo each fix | None: every reverted fix failed a test. |
| Test-suite reorganisation (#131) | 19 | The validator fuzzers only checked "accepted ⇒ valid": 5 over-rejecting mutants lived. Checked both ways, all are killed. |
| Memory bound (#120) | 5 | A larger write batch, until the test pinned the frame the stalled write carries. |
| Synchronisation without sleeps | 4 | A stale-read mutant in the coalesced stream reads, until each read's result carried its number. |
| The plan's named mutants (mA, mB, mE, mF, mI, mW) | 9 | mF, a feed that could not be released while blocked on the writer, until `TestStreamFeed_StopReleasesAFeedBlockedOnTheWriter`. |
| `select` release arms that can never fire | 13 | Three in `shared.go` (a leaked goroutine per stream) until `TestShared_EndedStreamsLeaveNoGoroutinesBehind`; Cleanup's wait until `TestHandler_Cleanup` required it to return at once without streams. |
| Documented configuration defaults | 3 | None. |

The code grew by the pull pipeline, shared subscriptions and stricter
configuration checks; every mutant gremlins could run was killed. Coverage
fell because the new code has more constants (timeouts, sentinels) and more
tagless switches (the formatter's escaping, configuration and replay
planning), which the coverage profile cannot mark; none of them survived
by hand.
